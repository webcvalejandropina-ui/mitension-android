# Mi Tensión Android 1.0.2 — lectura más clara

- Histórico más compacto: tipografía secundaria pequeña, separación reducida y divisores entre tomas del mismo periodo.
- Última toma: texto neutro de alto contraste cuando un valor está por debajo de la referencia, violeta solo para el valor que la supera.
- La sistólica y la diastólica se colorean por separado; el pulso no se marca en rojo automáticamente.
- Etiquetas de mañana con ámbar adaptable para mejorar contraste en claro y oscuro.

No cambia el formato de almacenamiento ni tus registros. Instala sobre la versión anterior sin desinstalar y conserva una copia Excel antes de actualizar.

APK firmado para pruebas, Android 8 o posterior. No es una publicación en Google Play. La revisión visual local usa datos sintéticos en Android TV API 34 con proporciones de teléfono; no utiliza capturas ni datos médicos del usuario. Sigue pendiente la validación en teléfono real y de las alarmas en condiciones reales.
